# Scoring, Rating, Matchmaking

## Scoring

Componenti:
- base risultato
- bonus prestazione
- fattore peso
- bonus speciale

Forfait:
- impatto minimo

Ritiro:
- impatto ridotto

## Rating

- tipo Elo
- aggiornato dopo ogni match
- impatto ridotto per:
  - ritiro
  - forfait

## Matchmaking

Basato su:
- peso
- level
- rating
- età
- storico incontri

Output:
- accoppiamenti suggeriti
- tutte le coppie candidate

Indice mismatch:
- più basso = meglio
