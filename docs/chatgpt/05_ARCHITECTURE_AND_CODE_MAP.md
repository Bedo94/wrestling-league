## Uso con ChatGPT

Quando chiedi modifiche:

1. Copia il file attuale dalla repo
2. Incollalo nella chat
3. Chiedi modifiche incrementali
4. Applica le modifiche nel codice locale
5. Commit + push su GitHub

NON chiedere mai di riscrivere file da zero se non necessario.
