# Project Overview

## Obiettivo

Creare una web app per gestire una wrestling league interna tra studenti.

Funzionalità principali:
- gestione atleti
- gestione eventi
- registrazione incontri
- scoring
- classifiche
- matchmaking automatico (con revisione manuale)

## Filosofia

- semplicità d’uso
- trasparenza delle regole
- flessibilità (parametri modificabili nel tempo)
- niente black-box

## Utenti

- organizzatori (admin)
- atleti (consultazione)
