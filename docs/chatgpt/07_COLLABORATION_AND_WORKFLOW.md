# Workflow

## Fonte di verità

- Codice → GitHub
- Documentazione → repo + ChatGPT Sources

## Flusso consigliato

1. Apri nuova chat nel Project
2. Incolla START_NEW_CHAT_PROMPT
3. Incolla il file su cui lavorare
4. Chiedi modifiche specifiche
5. Applica modifiche in locale
6. Commit + push

## Regole

- modifiche piccole e incrementali
- evitare refactor massivi non richiesti
- mantenere coerenza con struttura esistente
